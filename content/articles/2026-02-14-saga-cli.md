# Announcing the Saga CLI

[Saga](https://getsaga.dev) is a static site generator written in Swift, and it just got a lot easier to get started with. Saga now has a [companion CLI tool](https://github.com/loopwerk/saga-cli) with three commands: `saga init`, `saga build`, and `saga dev`.

## Installation

You can install the CLI system-wide via Homebrew:

```shell-session
$ brew install loopwerk/tap/saga
```

Or via Mint:

```shell-session
$ mint install loopwerk/saga-cli
```

## Getting started

Once installed, starting a new project is a single command:

```shell-session
$ saga init mysite
$ cd mysite
$ saga dev
```

`saga init` gives you a complete project with articles, tags, templates, and a stylesheet, ready to play around with.

## The dev server

`saga dev` watches your content and source folders for changes. When it detects a change, it triggers a rebuild and live-reloads the browser. It works on both macOS and Linux.

## Building for production

`saga build` compiles your site, ready to deploy.

## No more manual setup

Saga has always been a code-first tool without config files, and without magic conventions. But that also meant the getting started wasn't very easy. You had to start an Xcode project, add the dependencies, create your site pipeline from scratch. The new CLI makes all of this a lot easier, where you can have a running website in seconds, but still with full control over the entire pipeline.
