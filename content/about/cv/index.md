## Profile

I'm a product-minded senior software engineer with 25 years of experience. My focus is the logic that makes software tick: APIs and data models on the backend with Python and Django, and authentication, routing, and validation on the frontend with TypeScript and SvelteKit. I modernize legacy systems, take care of the infrastructure my software runs on, and beyond the code itself I guide the architecture, mentor the team, and help decide what's worth building.

Code quality and long-term maintainability matter deeply to me. I value pragmatic solutions that balance clarity and performance.

I've been building for the web since 2000 and working with Python since 2009. I'm a member of the Django Software Foundation, and my portfolio and open source projects can be found at [www.loopwerk.io](https://www.loopwerk.io).
